# Code of Conduct — FixPilot‑AI

This Code of Conduct outlines expectations for all contributors and community members interacting with the FixPilot‑AI project. Our goal is to maintain a respectful, safe, and productive environment for everyone.

---

## 🎯 Our Standards

We commit to creating a community where people:

- Treat each other with respect  
- Provide constructive feedback  
- Collaborate openly and honestly  
- Help others learn and grow  
- Maintain professionalism in all interactions  

---

## 🚫 Unacceptable Behavior

The following actions are not tolerated:

- Harassment, insults, or personal attacks  
- Discrimination or hateful conduct  
- Threats or intimidation  
- Sharing private information without consent  
- Posting malicious, harmful, or exploitative content  
- Disrupting discussions or sabotaging contributions  

---

## 🧭 Expected Behavior

All contributors should:

- Use welcoming and inclusive language  
- Respect differing viewpoints  
- Accept constructive criticism  
- Focus on what’s best for the project  
- Follow project structure and guidelines  
- Report issues responsibly  

---

## 🔐 Security & Safety

Do **not** submit:

- Exploits  
- Malware  
- Unsafe system calls  
- Code intended to bypass OS security  
- Anything that compromises user safety  

Security issues must be reported privately (see `SECURITY.md`).

---

## 🛠 Enforcement

Project maintainers may take action including:

- Warnings  
- Temporary or permanent bans  
- Rejection of contributions  
- Escalation to GitHub if necessary  

All decisions are made in the interest of community safety.

---

## 🤝 Scope

This Code of Conduct applies to:

- GitHub issues  
- Pull requests  
- Discussions  
- Project chat  
- Any public or private communication related to FixPilot‑AI  

---

## ⭐ Thank You

By participating in this project, you help build a strong, respectful, and innovative community.  
We appreciate your contributions and your commitment to keeping FixPilot‑AI safe and welcoming.
